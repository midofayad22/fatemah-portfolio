# Fatima Ezz — portfolio

Bilingual (Arabic default / English) static portfolio, deployed on Vercel from `main`.

| | |
|---|---|
| Live | https://fatemah-portfolio.vercel.app (Arabic) · `/en/` (English) |
| Stack | Plain HTML/CSS/JS generated by `scripts/build.mjs` (esbuild + sharp). No framework, no trackers. |
| Output | `dist/` (Vercel `outputDirectory`) |

## Commands
```
npm install
npm run build          # → dist/   (images are cached in .cache/ between builds)
npm run serve          # static server for dist/ on :4173 (cleanUrls like Vercel)
npm test               # 360+ browser checks (Playwright): routes, RTL/LTR, themes, gallery, lightbox, SW, SEO
npm run test:contrast  # WCAG AA check of every text/background token pair
node scripts/make-og.mjs   # regenerate public/og/*.jpg (committed)
```

## Where things live
- `content/site.json` – site URL, English/Arabic name, contact links (LinkedIn/Facebook/WhatsApp), `googleSiteVerification`.
- `content/gallery.json` – every image id, category, bilingual alt text. Source photos stay in `assets/` (untouched, still served at their old URLs).
- `content/literature.json` – verses (original Arabic with tashkeel).
- `content/i18n/{ar,en}.json` – all interface text. Build fails on a missing key.
- `src/css/*` – tokens (palette), base, layout, pages, gallery, motion. `src/js/*` – app, gallery/lightbox, PWA.
- `scripts/templates.mjs` – page templates (one render per language).

## Design system
Brand colours come from the original site: pink `#ec4899` / `#f472b6`, sky `#0284c7`, cyan `#00b4d8`, navy `#021526`, gradient cyan→pink. Text uses darker shades of the same hues in light mode (`#be185d`, `#0369a1`) to pass AA. Radii: 14 (images) / 18 / 26 (cards) / pill (buttons).

## Routes
`/`, `/about/`, `/gallery/`, `/literature/`, `/contact/` (Arabic) and the same under `/en/`. Gallery deep links: `?cat=photography|gardening|culture`, `?work=a14`.

## Deploy / manual steps
- Vercel builds with `npm run build` (see `vercel.json`); merging to `main` = production.
- Google Search Console: add the property, then either paste the verification token in `content/site.json → googleSiteVerification` or use DNS, and submit `/sitemap.xml`.
- Contact: no email address exists in the original project, so there is no form; add one to `site.json → contact` if wanted.
- PWA: installable on Chrome/Edge/Android; on iOS use Share → Add to Home Screen (the in-page install dialog explains this). It is a PWA, not a native app.
